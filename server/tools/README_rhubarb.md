# Rhubarb Lip Sync (not committed)

`app/lipsync.py` expects Rhubarb v1.14.0 (MIT licence) here:

    tools/rhubarb/Rhubarb-Lip-Sync-1.14.0-Windows/rhubarb.exe

Download `Rhubarb-Lip-Sync-1.14.0-Windows.zip` from
https://github.com/DanielSWolf/rhubarb-lip-sync/releases/tag/v1.14.0 and unzip it into `tools/rhubarb/`.
Without it the server still works; the headset falls back to its loudness-based mouth.
